# LUMA | Ideia Space

MVP educacional para a Ideia Space com frontend estatico, backend basico em Node.js e documentacao final da entrega.

## Como rodar localmente

```bash
npm start
```

Depois acesse:

- Site: http://localhost:3000
- API: http://localhost:3000/api/health
- Componentes: http://localhost:3000/api/components
- Telemetria: http://localhost:3000/api/telemetry
- Status da IA: http://localhost:3000/api/ai/status

## Hospedagem

O frontend pode ser hospedado pelo GitHub Pages. O backend Node fica disponivel localmente e preparado para uma futura hospedagem em servicos como Render, Railway ou Vercel.

## Estrutura

- `assets/`: frontend estatico do LUMA.
- `backend/`: servidor Node.js e dados demonstrativos.
- `Entrega_Final_LUMA/`: documentacoes e apresentacao final.
