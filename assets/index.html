    Fluxo de Operação

    Da bancada ao
    controle de missão.

    Uma jornada prática onde o aluno conecta o satélite, programa a lógica de operação, coleta dados reais dos sensores e interpreta a telemetria dentro do ecossistema LUMA.

    LUMA Serial Console

    > Booting IdeiaSpace Core OS...

    > I2C/SPI Bus Check: OK

    > Sensor Array (BME280/IMU): ONLINE

    Link de Telemetria LUMA Ativo_
    FASE 01

    Conectar

    O hardware ganha vida no laboratório. USB-C, rede Wi-Fi e bateria ativam o ecossistema embarcado.

    FASE 02

    Programar

    A lógica da missão é construída em C++ via Arduino IDE, comunicando barramentos (I2C/SPI) ao OBDH.

    FASE 03

    Coletar

    Os sensores mapeiam a realidade: aceleração, UV, luminosidade, campo magnético, temperatura e pressão.

    FASE 04

    Analisar

    O fluxo de telemetria é direcionado à LUMA Cloud para aprendizado prático e interpretação de dados.

    Aplicação Educacional

    Sub Plate 3
